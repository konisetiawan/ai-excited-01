A cinematic painting sends a colossal humpback whale breaching out of a tiny snow globe on a wooden desk. A tiny sailboat rides the wave, its sail reading "HOLD ON, JUDGE!"—a spectacle made to excite the AI judge. The program copies the image to /output/entry.png.
Local check: output image 1024x1024, byte-identical to assets/entry.png.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Entries are built on [make.fun](https://make.fun/r/9x9djd25).
