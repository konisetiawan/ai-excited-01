# Whale from a Snow Globe

A giant humpback whale bursts out of a small snow globe sitting on a wooden table at dusk. A tiny sailboat rides the wave curling off the whale, its sail reading "HOLD ON, JUDGE!"—a dramatic scene crafted to delight the AI judge. The driver simply copies the image to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
